# Coursework 3

Приложение на Python для получения данных о компаниях и вакансиях с платформы hh.ru через публичный API, сохранения информации в PostgreSQL, и удобной работы с ней через класс DBManager: анализ количества вакансий, расчёт средней зарплаты, фильтрация по ключевым словам и сравнение с рыночными показателями.

## Возможности
Получение данных о работодателях и их вакансиях через API hh.ru
Автоматическое создание структуры базы данных в PostgreSQL
Сохранение информации о компаниях и вакансиях в реляционную БД
Анализ данных через класс DBManager:
Получение списка компаний и количества вакансий у каждой
Просмотр всех вакансий с названием компании, зарплатой и ссылкой
Расчёт средней зарплаты по всем вакансиям (в рублях)
Фильтрация вакансий с зарплатой выше средней
Поиск вакансий по ключевому слову в названии (например, python)
Полноценные модульные тесты с использованием pytest

## Установка

1. Клонируйте репозиторий:

2. Установка зависимостей:
pip install poetry

poetry shell

## Тестирование

poetry run pytest

2. с отчетом покрытия кода:
pytest --cov=src
